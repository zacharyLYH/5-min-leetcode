Find Three Consecutive Integers That Sum to a Given Number

Medium Math, Simulation

Given an integer num, return three consecutive integers (as a sorted array) that sum to num. If num cannot be expressed as the sum of three consecutive integers, return an empty array.

 

Example 1:

Input: num = 33
Output: [10,11,12]
Explanation: 33 can be expressed as 10 + 11 + 12 = 33.
10, 11, 12 are 3 consecutive integers, so we return [10, 11, 12].

Example 2:

Input: num = 4
Output: []
Explanation: There is no way to express 4 as the sum of 3 consecutive integers.

 

Constraints:

  • 0 <= num <= 1015

Iterate starting from 0, checking if i + (i+1) + (i+2) equals num. — Directly implements the definition of three consecutive integers.
  • Exhaustive search becomes prohibitively slow for large num (up to 1e15).
  • Constant factor overhead for many redundant calculations.
Complexity: O(N) where N is approx num/3, infeasible for large inputs.
def find_three_consecutive(num):
    x = (num - 3) // 3
    if x + (x + 1) + (x + 2) == num:
        return [x, x + 1, x + 2]
    return []
Takeaway
Solve the linear equation algebraically for O(1) efficiency.
Center-value trick
Put one value in the middle, then take one step left and one step right. The three values always add to three times the middle, so divisibility by 3 tells you whether a valid middle exists.
Why it fits (4) — properties
  • The numbers sit one step around a center.
  • Their sum is always 3 times the center.
  • The center must be an integer.
  • The returned order is already sorted.
Spot it (3)
  • Three consecutive integers with a target sum.
  • A symmetric middle value can represent the whole group.
  • The target is huge, so exact divisibility is faster than trying starts.
How you'd derive it (first principles)
  1. Imagine choosing the middle number first.
  2. The other two must be one below and one above it.
  3. Their sum becomes 3 times the middle, so split num by 3 and check for a remainder.
Plan (4 steps)
  1. Check whether num is divisible by 3.
  2. Divide num by 3 to find the middle.
  3. Return middle - 1, middle, and middle + 1.
  4. Otherwise return an empty array.
Start when stuck: Name the unknown middle value. · Write the three values as middle - 1, middle, and middle + 1.
class Solution:

    def threeConsecutiveIntegers(self, num: int) -> list[int]:
        if num % 3 != 0:
            return []
        mid = num // 3
        return [mid - 1, mid, mid + 1]
Complexity: O(1) time, O(1) space

✅ Quick check

Q1: Why does checking divisibility by 3 tell us whether the three numbers exist?
Hint: Write the numbers around one middle value. What happens to one step down and one step up when you add them?
Let the middle number be m. The three numbers are m - 1, m, and m + 1. The -1 and +1 cancel, so the sum is always 3m. A valid target must divide evenly by 3.
Q2: If the target is not divisible by 3, can choosing a different starting number make it work? Why or why not?
Hint: The target divided by 3 should give the middle number. What would a remainder mean?
No. Every group of three consecutive integers has a sum that is a multiple of 3. If the target leaves a remainder after division by 3, no whole-number middle can produce it.

Checklist

If a fixed-size group is symmetric around one value, check whether its target sum is an exact multiple of the group size.
