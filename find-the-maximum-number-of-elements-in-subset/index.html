Find the Maximum Number of Elements in Subset

Medium Array, Hash Table, Enumeration

You are given an array of positive integers nums.

You need to select a subset of nums which satisfies the following condition:

  • You can place the selected elements in a 0-indexed array such that it follows the pattern: [x, x2, x4, ..., xk/2, xk, xk/2, ..., x4, x2, x] (Note that k can be any non-negative power of 2). For example, [2, 4, 16, 4, 2] and [3, 9, 3] follow the pattern while [2, 4, 8, 4, 2] does not.

Return the maximum number of elements in a subset that satisfies these conditions.

 

Example 1:

Input: nums = [5,4,1,2,2]
Output: 3
Explanation: We can select the subset {4,2,2}, which can be placed in the array as [2,4,2] which follows the pattern and 22 == 4. Hence the answer is 3.

Example 2:

Input: nums = [1,3,2,4]
Output: 1
Explanation: We can select the subset {1}, which can be placed in the array as [1] which follows the pattern. Hence the answer is 1. Note that we could have also selected the subsets {2}, {3}, or {4}, there may be multiple subsets which provide the same answer.

 

Constraints:

  • 2 <= nums.length <= 105
  • 1 <= nums[i] <= 109

Brute-force subset enumeration. — Try every subset, sort it, then test paired values and square jumps.
  • Input size: n = 10^5 gives 2^n subsets.
  • Repeated work: duplicate-valued subsets are repeatedly sorted and checked.
Complexity: O(2^n * n log n) time; O(n) extra space.
from itertools import combinations

def follows_pattern(a):
    return (n := len((a := sorted(a)))) % 2 == 1 and all((a[2 * i] == a[2 * i + 1] and (i == 0 or a[2 * i] == a[2 * i - 2] ** 2) for i in range(n // 2)))

def naive(nums):
    best = 1
    for size in range(1, len(nums) + 1, 2):
        for subset in combinations(nums, size):
            if follows_pattern(subset):
                best = size
    return best
Takeaway
Ditch brute force when n is large and subsets overlap; use frequencies and enumerate square chains.
symmetric power chain
A valid subset can be rearranged into a chain that rises by squaring and then falls back in the same order. Each lower power needs two copies, one on each side; the highest power needs one copy in the middle. So start from a base number and ask how far this two-sided chain can grow.
Why it fits (4) — properties
  • The chain order is fixed once you choose the base x.
  • Squaring grows very fast, so each chain is short under 1e9.
  • Lower levels need pairs; only the top level needs one copy.
  • Duplicates matter because the left and right sides consume the same values.
Spot it (3)
  • The statement gives an exact up-then-down pattern: x, x^2, x^4, ... , x^4, x^2, x.
  • Numbers are positive and up to 1e9, so repeated squaring creates only a few levels.
  • You choose a subset, so duplicate counts decide whether a level can be mirrored.
How you'd derive it (first principles)
  1. Imagine you pick the first number, x. Then the next number is forced: x^2, then x^4, then x^8, and so on.
  2. If you stop at x^k, the right half is forced to mirror the left half, with x^k used once.
  3. So instead of searching subsets, try each possible x and extend the forced chain.
  4. Count duplicates first, because pairs decide whether a level can appear on both sides.
Plan (5 steps)
  1. Count numbers with a count table.
  2. Handle 1 separately: all 1s can form a valid subset.
  3. For each x > 1, walk v = x, v^2, v^4, ...
  4. Add 2 when v can be used on both sides and the next value exists.
  5. Otherwise add 1 for the middle and stop; keep the best total.
Start when stuck: Count how many times each number appears. · Test the smallest useful chain: can you make [x, x^2, x]? If yes, try extending to [x, x^2, x^4, x^2, x].
total = 0
v = x
while True:
    if cnt[v] == 0:
        break
    next_v = v * v
    if next_v <= 10 ** 9 and cnt[next_v] > 0 and (cnt[v] > 1):
        total += 2
        v = next_v
    else:
        total += 1
        break
ans = max(ans, total)

Q1: Why does the symmetric power chain pattern require a frequency table, and what breaks if duplicates are missing?
Hint: Think about why the chain must be symmetric and how duplicates are used on both sides.
The pattern requires a symmetric chain that goes up by squaring and then mirrors back. This means each level (except the top) must have at least two copies to appear on both sides. The frequency table ensures we have enough copies for each level.
