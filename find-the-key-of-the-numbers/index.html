Find the Key of the Numbers

You are given three positive integers num1, num2, and num3.

The key of num1, num2, and num3 is defined as a four-digit number such that:

  • Initially, if any number has less than four digits, it is padded with leading zeros.
  • The ith digit (1 <= i <= 4) of the key is generated by taking the smallest digit among the ith digits of num1, num2, and num3.

Return the key of the three numbers without leading zeros (if any).

 

Example 1:

Input: num1 = 1, num2 = 10, num3 = 1000

Output: 0

Explanation:

On padding, num1 becomes "0001", num2 becomes "0010", and num3 remains "1000".

  • The 1st digit of the key is min(0, 0, 1).
  • The 2nd digit of the key is min(0, 0, 0).
  • The 3rd digit of the key is min(0, 1, 0).
  • The 4th digit of the key is min(1, 0, 0).

Hence, the key is "0000", i.e. 0.

Example 2:

Input: num1 = 987, num2 = 879, num3 = 798

Output: 777

Example 3:

Input: num1 = 1, num2 = 2, num3 = 3

Output: 1

 

Constraints:

  • 1 <= num1, num2, num3 <= 9999

  • The naive code checks every pair of numbers directly and picks the smaller one; it works quickly when there are only three short numbers but slows down if you add more numbers or make them longer.
  • The gold code treats the three numbers as four vertical columns, finds the smallest digit in each column, and joins those smallest digits together. It stays fast no matter how many numbers you have, because each column is processed independently.

Complexity: O(1)
def key_of_numbers(num1, num2, num3):
    s1 = str(num1).zfill(4)
    s2 = str(num2).zfill(4)
    s3 = str(num3).zfill(4)
    key_str = ''
    for i in range(4):
        key_str += min(s1[i], s2[i], s3[i])
    return int(key_str)
Takeaway
Use when numbers are small and fixed-length; avoid if input size grows or numbers become very large.
Vertical Minimum Extraction
Treat the three numbers as columns of equal height (4 rows). Instead of comparing them globally, you look down each column, grab the digits from all three numbers at that position, and pick the smallest one. String each chosen digit into a new number.

  • Calculation happens independently for each of the four positions.
  • No interaction exists between different positions—one calculation doesn't change others.

How you'd derive it (first principles)
  1. Write out the three numbers with leading zeros so they all have 4 slots.
  2. For slot 1, read the top digit of each number and take the smallest.
  3. Repeat this for slots 2, 3, and 4, building the answer string piece by piece.

def find_the_key(num1, num2, num3):
    s1 = str(num1).zfill(4)
    s2 = str(num2).zfill(4)
    s3 = str(num3).zfill(4)
    key = ''
    for i in range(4):
        key += min(s1[i], s2[i], s3[i])
    return int(key)
Complexity: O(1) — only 4 comparisons regardless of input size.
