Minimum Operations to Write the Letter Y on a Grid

Medium Array, Hash Table, Matrix, Counting

You are given a 0-indexed n x n grid where n is odd, and grid[r][c] is 0, 1, or 2.

We say that a cell belongs to the Letter Y if it belongs to one of the following:

  • The diagonal starting at the top-left cell and ending at the center cell of the grid.
  • The diagonal starting at the top-right cell and ending at the center cell of the grid.
  • The vertical line starting at the center cell and ending at the bottom border of the grid.

The Letter Y is written on the grid if and only if:

  • All values at cells belonging to the Y are equal.
  • All values at cells not belonging to the Y are equal.
  • The values at cells belonging to the Y are different from the values at cells not belonging to the Y.

Return the minimum number of operations needed to write the letter Y on the grid given that in one operation you can change the value at any cell to 0, 1, or 2.

Constraints:

  • 3 <= n <= 49
  • n == grid.length == grid[i].length
  • 0 <= grid[i][j] <= 2
  • n is odd.

  • Gold sees that all Y‑cells must become the same symbol and everything else must become a different symbol, then counts how many cells already match each possible symbol so you can pick the cheapest combination without guessing.

Exhaustive Assignment — Directly tries every possible value (0, 1, 2) for every cell in the Y shape.
  • State space grows exponentially as O(3^|Y|), becoming infeasible for larger grids.
  • Repeated recalculation of cell contributions across brute-force branches wastes computation.
Complexity: O(n^2) time, O(n^2) space
import collections

def minOperations(grid):
    n = len(grid)
    y_cells = []
    other_cells = []
    for r in range(n):
        for c in range(n):
            if r == c or r + c == n - 1 or c == n // 2:
                y_cells.append((r, c))
            else:
                other_cells.append((r, c))
    cnt_y = collections.Counter((v for _, v in y_cells))
    cnt_other = collections.Counter((v for _, v in other_cells))
    ans = float('inf')
    for y_val in range(3):
        for o_val in range(3):
            if y_val == o_val:
                continue
            cost_y = len(y_cells) - cnt_y.get(y_val, 0)
            cost_other = len(other_cells) - cnt_other.get(o_val, 0)
            ans = min(ans, cost_y + cost_other)
    return ans
Takeaway
Do not enumerate assignments. Use histograms: the optimal target color for a set is its most frequent value in that set. Pick two distinct colors for Y and non-Y sets.
Frequency Counting with Small Alphabet
We have two groups of cells, Y and non‑Y. We need to pick one number for all Y cells and a different number for all non‑Y cells. By counting how many cells in each group already have each possible value (0,1,2), we can quickly compute the cost of any assignment and choose the cheapest.
Why it fits (3) — properties
  • Alphabet size is only 3, so we can try all 6 ordered pairs of distinct values.
  • Grid size up to 49×49, so O(n²) counting is fine.
  • Groups are defined by simple geometric rules, easy to test membership.
Spot it (1)
  • When you must assign one of a tiny set of labels to each cell and minimize changes, and the cells are partitioned into two fixed groups.
How you'd derive it (first principles)
  1. Imagine you want to make the Y shape all one color and the background another color, but you can only use three colors.
  2. You could try each possible pair of colors: for each pair, count how many Y cells are not the chosen Y‑color plus how many background cells are not the chosen background color.
  3. The pair with the smallest total is the answer. This works because the cost separates per group and the groups are independent.
Plan (5 steps)
  1. 1. Determine n and center.
  2. 2. For each cell, check if it belongs to Y using row,col conditions.
  3. 3. Tally counts of 0,1,2 in Y and outside Y.
  4. 4. For each a in {0,1,2}, for each b in {0,1,2} with a≠b, compute cost = (sizeY - cntY[a]) + (sizeNonY - cntNonY[b]).
  5. 5. Return minimum cost.

cntY = [0, 0, 0]
cntN = [0, 0, 0]
for r in range(n):
    for c in range(n):
        if r == c or r + c == n - 1 or (c == n // 2 and r >= n // 2):
            cntY[grid[r][c]] += 1
        else:
            cntN[grid[r][c]] += 1
best = min((sum(cntY) - cntY[a] + sum(cntN) - cntN[b] for a in range(3) for b in range(3) if a != b))

✅ Quick check

Q1: Why does looking at how often each digit appears let you calculate the cheapest total cost?
Hint: Imagine you decide the Y shape must be red; every red cell saves money, while every blue or green cell forces a rewrite.
Because changing a cell costs nothing if it already has the right digit, so the cost for a target digit equals the number of cells that would still need changing.
Q2: What step guarantees you won’t miss the lowest cost when several digits tie as good choices?
Hint: With only three possible symbols (0, 1, 2), you only have six ways to pick a Y‑color and a background‑color pair.
Try every ordered pair of distinct digits (there are only six such pairs) and keep the smallest total cost.

Checklist

Count frequencies of each value in the two groups, then try all distinct pairs to find minimum changes.
