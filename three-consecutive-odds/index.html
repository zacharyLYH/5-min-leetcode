Three Consecutive Odds

Given an integer array arr, return true if there are three consecutive odd numbers in the array. Otherwise, return false.

 

Example 1:

Input: arr = [2,6,4,1]
Output: false
Explanation: There are no three consecutive odds.

Example 2:

Input: arr = [1,2,34,3,4,5,7,23,12]
Output: true
Explanation: [5,7,23] are three consecutive odds.

 

Constraints:

  • 1 <= arr.length <= 1000
  • 1 <= arr[i] <= 1000

Brute-force triplet scan — Directly iterates through indices using nested loops to test every possible group of three elements.
  • Examines O(N³) triplets instead of just adjacent windows, causing cubic time blowup.
  • Redundantly rechecks parity for overlapping segments, wasting cycles.
Complexity: O(N³) naive time, O(N) optimal time
def three_consecutive_odds(arr):
    n = len(arr)
    for i in range(n - 2):
        if arr[i] % 2 and arr[i + 1] % 2 and arr[i + 2] % 2:
            return True
    return False
Takeaway
Maintain a running streak of odds; return true immediately upon reaching three consecutive matches.
Running Counter
Walk through the list and keep a counter of how many odd numbers you've seen in a row. If the counter ever reaches three, you know the answer is true. When you encounter an even number, you reset the counter to zero.
Why it fits (3) — properties
  • Only parity matters, not the actual values.
  • The requirement is three consecutive odds, so a running count works.
  • The array size is small, so linear scan is efficient.
Spot it (3)
  • Need to find three consecutive odd numbers
  • Array elements are integers, only odd/even matters
  • Length up to 1000, O(n) is acceptable
How you'd derive it (first principles)
  1. Imagine you're scanning the array one element at a time.
  2. When you see an odd number, you start a streak; if the next is also odd, the streak grows.
  3. If it reaches three, you've found the answer; if an even appears, the streak breaks and you start over.
Plan (5 steps)
  1. Initialize counter to 0
  2. Iterate over each element
  3. If element is odd, increase counter, else reset counter
  4. If counter reaches 3, return true
  5. After iteration, return false
Start when stuck: Initialize a variable streak to 0. · Loop through each number, updating streak based on whether the number is odd.
def three_consecutive_odds(arr):
    streak = 0
    for num in arr:
        if num % 2 == 1:
            streak += 1
            if streak == 3:
                return True
        else:
            streak = 0
    return False
Complexity: O(n)

✅ Quick check

Q1: Why does resetting the count to zero when you see an even number give the correct answer?
Hint: Imagine you kept the old count after an even; what would that count represent?
Because an even number breaks any chance of having three odds in a row, so you must start counting again from the next element.
Q2: What would go wrong if you only looked at every third element instead of each element while scanning?
Hint: Consider a list where the odds begin at the second element.
You could miss a run of three odds that starts at an index not divisible by three, making you think there is no run when there actually is one.

Checklist

Scan the array while maintaining a streak counter, reset on even numbers, and return true if the streak reaches three.
