Minimum Height Trees

A tree is an undirected graph in which any two vertices are connected by exactly one path. In other words, any connected graph without simple cycles is a tree.

Given a tree of n nodes labelled from 0 to n - 1, and an array of n - 1 edges where edges[i] = [ai, bi] indicates that there is an undirected edge between the two nodes ai and bi in the tree, you can choose any node of the tree as the root. When you select a node x as the root, the result tree has height h. Among all possible rooted trees, those with minimum height (i.e. min(h))  are called minimum height trees (MHTs).

Return a list of all MHTs' root labels. You can return the answer in any order.

The height of a rooted tree is the number of edges on the longest downward path between the root and a leaf.

 

Example 1:

Input: n = 4, edges = [[1,0],[1,2],[1,3]]
Output: [1]
Explanation: As shown, the height of the tree is 1 when the root is the node with label 1 which is the only MHT.

Example 2:

Input: n = 6, edges = [[3,0],[3,1],[3,2],[3,4],[5,4]]
Output: [3,4]

 

Constraints:

  • 1 <= n <= 2 * 104
  • edges.length == n - 1
  • 0 <= ai, bi < n
  • ai != bi
  • All the pairs (ai, bi) are distinct.
  • The given input is guaranteed to be a tree and there will be no repeated edges.

Pick any root, run DFS/BFS to compute depths, then keep the root with smallest maximum depth. — Intuitive: shorter paths from the centre minimise overall height.
  • Repeated full traversals cost O(n^2) for large n.
  • Each vertex is removed many times instead of being processed once.
Complexity: O(n) time, O(n) extra space
def findMinHeightTrees(n, edges):
    if n <= 1:
        return list(range(n))
    adj = [[] for _ in range(n)]
    deg = [0] * n
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)
        deg[u] += 1
        deg[v] += 1
    leaves = [i for i in range(n) if deg[i] == 1]
    cnt = n
    while cnt > 2:
        new_leaves = []
        for leaf in leaves:
            for nb in adj[leaf]:
                deg[nb] -= 1
                if deg[nb] == 1:
                    new_leaves.append(nb)
            leaves.remove(leaf)
        leaves = new_leaves
        cnt -= len(new_leaves)
    return leaves
Takeaway
Leaf‑pruning (centroid removal) gives linear runtime, beating naïve repeated traversals.
Leaf peeling (topological sort)
In a tree, the center nodes give minimum height. By repeatedly removing all leaf nodes (degree 1) we shrink the tree toward its center. The last one or two nodes are the MHT roots.
Why it fits (3) — properties
  • The graph is a tree with n-1 edges, connected, acyclic.
  • Leaves have degree 1; removing a leaf reduces neighbor degree and may create new leaves.
  • The process ends at the tree's center, which lies on any longest path.
Spot it (3)
  • You need to find roots that minimize the maximum distance to any leaf in a tree.
  • You can iteratively strip away nodes of degree 1.
  • The answer is either one node or two adjacent nodes.
How you'd derive it (first principles)
  1. Think of the tree as a graph where the farthest nodes are leaves.
  2. To minimize height, pick a root near the middle of the longest path.
  3. Peel off outer leaves layer by layer; what remains is the middle.
Plan (4 steps)
  1. Build adjacency list and degree array from edges.
  2. Initialize a queue with all leaves (degree 1).
  3. While more than 2 nodes remain, remove current leaves, decrease neighbor degrees, and add new leaves.
  4. Return the remaining nodes.
Start when stuck: Create an adjacency list and compute each node's degree. · Collect all nodes with degree 1 as initial leaves.
def findMinHeightTrees(n, edges):
    if n == 1:
        return [0]
    adj = [[] for _ in range(n)]
    deg = [0] * n
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)
        deg[u] += 1
        deg[v] += 1
    leaves = [i for i in range(n) if deg[i] == 1]
    remaining = n
    while remaining > 2:
        remaining -= len(leaves)
        new_leaves = []
        for leaf in leaves:
            for neighbor in adj[leaf]:
                deg[neighbor] -= 1
                if deg[neighbor] == 1:
                    new_leaves.append(neighbor)
        leaves = new_leaves
    return leaves
Complexity: O(n)

✅ Quick check

Q1: Why can we remove all outer one-connection nodes together? What breaks if the graph has a loop?
Hint: Think of peeling an onion. A loop is a ring that never fully peels.
They are farthest from the middle. Removing them shrinks the tree from all sides at the same time. A loop keeps extra paths, so nodes may not become one-connection and the middle can be wrong or never reached.
Q2: Why can the answer be two next-to-each-other nodes? What decides one vs two?
Hint: Draw a line of 3 nodes vs 4 nodes. Where is the middle?
The middle of the longest line of nodes can be a node or the gap between two nodes. If the middle is a node, one answer. If it is between two nodes, both are equally good. A tree has one clear longest spine, so only these centers work.
