Maximum Area Rectangle With Point Constraints I

Medium Array, Math, Binary Indexed Tree, Segment Tree, Geometry, Sorting, Enumeration

You are given an array points where points[i] = [xi, yi] represents the coordinates of a point on an infinite plane.

Your task is to find the maximum area of a rectangle that:

  • Can be formed using four of these points as its corners.
  • Does not contain any other point inside or on its border.
  • Has its edges parallel to the axes.

Return the maximum area that you can obtain or -1 if no such rectangle is possible.

 

Example 1:

Input: points = [[1,1],[1,3],[3,1],[3,3]]

Output: 4

Explanation:

We can make a rectangle with these 4 points as corners and there is no other point that lies inside or on the border. Hence, the maximum possible area would be 4.

Example 2:

Input: points = [[1,1],[1,3],[3,1],[3,3],[2,2]]

Output: -1

Explanation:

There is only one rectangle possible is with points [1,1], [1,3], [3,1] and [3,3] but [2,2] will always lie inside it. Hence, returning -1.

Example 3:

Input: points = [[1,1],[1,3],[3,1],[3,3],[1,2],[3,2]]

Output: 2

Explanation:

The maximum area rectangle is formed by the points [1,3], [1,2], [3,2], [3,3], which has an area of 2. Additionally, the points [1,1], [1,2], [3,1], [3,2] also form a valid rectangle with the same area.

 

Constraints:

  • 1 <= points.length <= 10
  • points[i].length == 2
  • 0 <= xi, yi <= 100
  • All the given points are unique.

Complexity: O(n³)
def maxArea(points):
    s = {tuple(p) for p in points}
    ans = 0
    n = len(points)
    for i in range(n):
        x1, y1 = points[i]
        for j in range(i + 1, n):
            x2, y2 = points[j]
            if x1 == x2 or y1 == y2:
                continue
            if (x1, y2) in s and (x2, y1) in s:
                ok = True
                for x, y in points:
                    if min(x1, x2) <= x <= max(x1, x2) and min(y1, y2) <= y <= max(y1, y2):
                        if (x, y) not in {(x1, y1), (x1, y2), (x2, y1), (x2, y2)}:
                            ok = False
                            break
                if ok:
                    ans = max(ans, abs(x1 - x2) * abs(y1 - y2))
    return ans if ans else -1

Brute Force Enumeration
Iterate through all possible pairs of unique x-coordinates to represent left/right edges, and all pairs of unique y-coordinates to represent bottom/top edges. For each candidate pair, treat the four intersections as potential rectangle corners. Validate that all four corners exist in the input set and verify that no other point lies strictly inside the resulting bounding box.
Why it fits (3) — properties
  • Small input size (≤10 points) permits exhaustive checking of every geometric configuration rather than relying on advanced data structures.
  • An axis-aligned rectangle is completely defined by selecting two distinct x-values and two distinct y-values.
  • The 'empty' condition means no additional point can share an x-range and y-range simultaneously inside the box.
Spot it (3)
  • The requirement for axis-parallel edges forces rectangles to be defined purely by their extreme x and y coordinates.
  • Because the point set must not contain any other point on the border or inside, a simple existence check combined with an interior sweep is sufficient validation.
  • The low constraints on the total number of points make an O(N^4) search approach computationally trivial.
How you'd derive it (first principles)
  1. Imagine that for a rectangle to exist, you must first decide its left and right limits (two different x-values) and its bottom and top limits (two different y-values).
  2. Once you fix these four limits, the four corners are mathematically fixed, so you just need to check if all four corners actually appear in your list of points.
  3. After confirming the corners are present, you must scan the remaining points to ensure none sneak inside the open interval between those limits.
Plan (6 steps)
  1. Generate all combinations of 2 items from the x-coordinates list.
  2. For each x-pair, generate all combinations of 2 items from the y-coordinates list.
  3. Calculate the width and height for the current rectangle.
  4. Check if all four corner coordinates exist in the original set.
  5. Verify no other point lies within the strict interior bounds.
  6. Update the global maximum area if this rectangle is valid.
Start when stuck: Convert the point list into a set of tuples for O(1) membership tests. · Collect and sort unique x and y coordinates separately.
import itertools

def largestRectangle(points):
    s = set(map(tuple, points))
    xs = sorted({p[0] for p in s})
    ys = sorted({p[1] for p in s})
    best = -1
    for x_left, x_right in itertools.combinations(xs, 2):
        for y_bottom, y_top in itertools.combinations(ys, 2):
            corners = ((x_left, y_bottom), (x_left, y_top), (x_right, y_bottom), (x_right, y_top))
            if all((c in s for c in corners)):
                okay = True
                for p in s:
                    px, py = p
                    if x_left < px < x_right and y_bottom < py < y_top:
                        okay = False
                        break
                if okay:
                    best = max(best, (x_right - x_left) * (y_top - y_bottom))
    return best
Complexity: O(U_x^2 * U_y^2) where U_x and U_y are the counts of unique x and y coordinates. Given N ≤ 10, this simplifies to a very small constant-time operation.

✅ Quick check

Q1: Why does the gold method suggest gathering all unique x and y values before forming rectangles?
Hint: Think of building a fence. You only need to pick where the posts go (unique x and y spots), not every single tree (every point).
A rectangle is completely defined by its left wall, right wall, bottom wall, and top wall. These are just lines (x and y positions), not individual dots. Grouping removes repeated lines and focuses only on the boundary lines.
Q2: After finding four corners, what final check ensures the rectangle is valid?
Hint: Imagine closing a net around two dots. If there is any loose dot floating inside that net, the net isn't a true rectangle anymore.
You must verify that no other dots are hidden inside the box formed by the corners.

Checklist

If you need to maximize area under axis-parallel constraints, enumerate every pair of x-bounds and y-bounds, then verify corner existence and interior emptiness. The small input size guarantees this brute-force search is safe and fast.
