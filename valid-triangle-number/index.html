Valid Triangle Number

Medium Array, Two Pointers, Binary Search, Greedy, Sorting

Given an integer array nums, return the number of triplets chosen from the array that can make triangles if we take them as side lengths of a triangle.

 

Example 1:

Input: nums = [2,2,3,4]
Output: 3
Explanation: Valid combinations are: 
2,3,4 (using the first 2)
2,3,4 (using the second 2)
2,2,3

Example 2:

Input: nums = [4,2,3,4]
Output: 4

 

Constraints:

  • 1 <= nums.length <= 1000
  • 0 <= nums[i] <= 1000

TL;DR — 30s scan

  • Naive tries every possible group of three numbers one by one, which becomes incredibly slow and hits limits very fast.
  • Gold sorts the numbers first, turning the hard search into a quick scan where you can count many valid groups at once.
Spot next time: If you need to count sets of numbers that fit a rule, remember to put them in order first so you can skip impossible cases with pointers.

Triple nested loops — Directly checks every combination of three numbers to see if they satisfy the triangle inequality.
  • Cubic time complexity O(N^3) exceeds limits for N=1000 (~10^9 ops)
  • Repeatedly scans the same sub-arrays without pruning
Complexity: O(N^2) time, O(1) extra space after sorting
def validTriangleNumber(nums):
    nums.sort()
    n = len(nums)
    count = 0
    for k in range(n - 1):
        i, j = (0, k - 1)
        while i < j:
            if nums[i] + nums[j] > nums[k]:
                count += j - i
                j -= 1
            else:
                i += 1
    return count
Takeaway
Sort and use two-pointers; never brute-force triplets.
Sort, fix the largest side, then count with two pointers
Sort the side lengths first. For one fixed largest side, compare the smallest remaining side with the largest remaining candidate; the result tells you whether to count many pairs at once or move a pointer.
Why it fits (3) — properties
  • After sorting, for sides a <= b <= c, only a + b > c needs checking.
  • For a fixed largest side, moving the smaller pointer right makes sums larger; moving the larger pointer left makes sums smaller.
  • Duplicate values count as different array positions, so sorting keeps them naturally.
Spot it (3)
  • Count triplets that must satisfy a triangle inequality.
  • Values can be sorted without changing the chosen indices.
  • For each largest side, many pair checks can be replaced by pointer movement.
How you'd derive it (first principles)
  1. Imagine sorting three chosen sides. The two smaller sides are the only possible trouble; if they beat the largest side, the other triangle checks are automatic.
  2. Now fix the largest side and look at the smallest plus largest remaining candidate. If that sum is too small, the smallest side cannot work with any candidate, so move it right.
  3. If that sum is big enough, the same largest candidate works with every side from the smallest pointer through just before it, so count them all and move that candidate left.
Plan (5 steps)
  1. Sort the array.
  2. Loop the largest-side index from the end down to 2.
  3. Set one pointer at 0 and one just before the largest side.
  4. If their sum is large enough, add right - left and move right left; otherwise move left right.
  5. Return the total.
Start when stuck: Sort nums. · Fix the rightmost index as the largest side, then place two pointers on the earlier indices.

    left = 0
    right = k - 1

            ans += right - left
            right -= 1
        else:

Complexity: O(n log n) time; O(1) extra space if sorting in place.

✅ Quick check

Q1: Why does putting the numbers in order allow you to skip checking most pairs instead of doing math on every single one?
Hint: Think about how 'stronger' means having a bigger sum.
Because if the two smallest numbers left of the largest one are not strong enough to beat it, then nothing further to the right will work too. If they are strong enough, the power stays high for every number in between, so you count all of them at once.
Q2: When the two smaller numbers make a sum big enough, what does the code count and why?
Hint: Relate this to grouping similar sized items together.
It counts how many numbers exist between the two pointers. Since the list is sorted, if the sum is good, every number in that range automatically makes a valid triangle with the current largest number.

Checklist

If you need to count triplets whose sorted side lengths satisfy the triangle rule, sort once, fix the largest side, and use two pointers to count valid smaller-side pairs.
