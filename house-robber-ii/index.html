You are a professional robber planning to rob houses along a street. Each house has a certain amount of money stashed. All houses at this place are arranged in a circle. That means the first house is the neighbor of the last one. Meanwhile, adjacent houses have a security system connected, and it will automatically contact the police if two adjacent houses were broken into on the same night.

Given an integer array nums representing the amount of money of each house, return the maximum amount of money you can rob tonight without alerting the police.

 

Example 1:

Input: nums = [2,3,2]
Output: 3
Explanation: You cannot rob house 1 (money = 2) and then rob house 3 (money = 2), because they are adjacent houses.

Example 2:

Input: nums = [1,2,3,1]
Output: 4
Explanation: Rob house 1 (money = 1) and then rob house 3 (money = 3).
Total amount you can rob = 1 + 3 = 4.

Example 3:

Input: nums = [1,2,3]
Output: 3

 

Constraints:

  • 1 <= nums.length <= 100
  • 0 <= nums[i] <= 1000

Exhaustive subset search — A robber might try every possible set of non‑adjacent houses to maximize loot.
  • With up to 100 houses, enumerating all 2^100 subsets is computationally impossible.
  • The same sub‑problems are recomputed many times leading to massive redundancy.
Complexity: O(2^n) – exponential growth.
def max_rob_bruteforce(nums):
    n = len(nums)
    best = 0
    for mask in range(1 << n):
        cur = 0
        for i in range(n):
            if mask >> i & 1:
                if i == 0 or nums[i - 1] + 1 != i:
                    cur += nums[i]
        if cur > best:
            best = cur
    return best
Takeaway
Ditch exhaustive search when n grows beyond ~20; use linear DP instead.
Break Circle into Two Lines
When houses are in a circle, the first and last are adjacent, so you cannot rob both. The trick is to imagine cutting the circle between the first and last house, creating two separate linear streets: one that includes the first house but not the last, and another that includes the last but not the first. You then solve the simpler linear problem on each street and take the better result.
Why it fits (3) — properties
  • The circular adjacency constraint can be removed by considering two linear subarrays.
  • The linear version has optimal substructure: the best amount up to house i depends only on the best up to i-1 and i-2, so a simple DP works.
  • The two subproblems are independent and cover all possibilities.
Spot it (3)
  • When the array is circular and adjacent houses cannot both be robbed.
  • When you need to maximize sum with no two consecutive elements.
  • When you can split the circle into two linear cases by excluding one end.
How you'd derive it (first principles)
  1. Imagine you notice that if you rob the first house, you can't rob the last, so the problem splits into two cases: either you skip the last house, or you skip the first. For each case, you have a straight line of houses.
  2. You then think: for a straight line, you can go house by house, at each step deciding whether to rob it or not, keeping track of the best you can do up to that house. This leads to a simple rule: the best at house i is either the best from before plus this house, or just the best from the previous house.
Plan (4 steps)
  1. Check if there's only one house, return its value.
  2. Define a function that takes a list and returns the max money for a linear street.
  3. Call that function on nums[0:-1] and nums[1:].
  4. Return the maximum of the two results.
Start when stuck: Write a helper function that solves the linear version (like the original House Robber). · Then call it on the array without the last element and on the array without the first element, and return the larger of the two.
def rob(nums):
    if len(nums) == 1:
        return nums[0]

    def rob_linear(arr):
        prev2 = 0
        prev1 = 0
        for x in arr:
            curr = max(prev1, prev2 + x)
            prev2 = prev1
            prev1 = curr
        return prev1
    return max(rob_linear(nums[:-1]), rob_linear(nums[1:]))
Complexity: O(n) time, O(1) extra space

✅ Quick check

Q1: Why does cutting the circle between the first and last house let us reuse the same method that works for a straight line?
Hint: Think about which houses become neighbors after you remove the connection between the ends.
After the cut, the first and last houses are no longer next to each other, so the adjacency rule only matters inside each piece, making each piece a normal line problem.
Q2: What goes wrong if we just apply the straight‑line method to the whole circular array without splitting?
Hint: Consider a case where the first and last houses hold the most money.
We might end up taking both the first and last house, which are actually neighbors in the circle, giving a total that is too high.
